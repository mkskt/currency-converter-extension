# Currency Converter

**A lightweight, efficient browser extension to instantly convert prices across websites.**

---

## 🚀 Key Features

* **Instant Conversion:** Simply highlight any price on a webpage to see real-time conversions.
* **Smart Selection:** Supports multiple target currencies based on your preferences.
* **Privacy Focused:** Operates 100% client-side. No tracking, no telemetry, no data collection.
* **Customizable:** Use activation keys to avoid triggering the tool accidentally.
* **Domain Blacklisting:** Easily exclude specific websites where you don't need conversions.
* **Dark Mode:** Seamlessly adapts to your browser theme.

---

## 🛠️ How to Install

Since this is an open-source project, you can install it manually in a few steps:

1.  **Download:** [Download the latest release zip file here](link-to-your-github-release).
2.  **Extract:** Unzip the folder to a location on your computer.
3.  **Open Extensions:** Navigate to your browser's extensions page (`chrome://extensions` or `opera://extensions`).
4.  **Developer Mode:** Toggle **"Developer mode"** in the top right corner.
5.  **Load Unpacked:** Click the **"Load unpacked"** button and select the folder you just extracted.

---

## 📖 How to Use

* **Highlight:** Select any price text on a website with your mouse.
* **View:** The conversion tooltip will appear automatically.
* **Copy:** Click any row in the tooltip to copy the converted value to your clipboard.
* **Settings:** Click the extension icon to select your preferred currencies, set activation keys, or manage your blacklist.

---

## 🔒 Privacy Policy

Your privacy is our priority. This extension performs all calculations **locally on your machine**. We do not track your browsing history, store your financial data, or send any information to external servers.
